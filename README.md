Calculadora em Python

Projeto simples desenvolvido em Python: uma calculadora de terminal com as quatro operações matemáticas básicas, mais uma função extra de cálculo de IMC (Índice de Massa Corporal).

Objetivo

O projeto foi criado como parte do meu portfólio de programação, com o objetivo de praticar lógica básica, organização de código em funções, tratamento de erros e interação com o usuário via terminal.

Funcionalidades
Soma
Subtração
Multiplicação
Divisão (com tratamento de divisão por zero)
Cálculo de IMC, com classificação automática (abaixo do peso, peso normal, sobrepeso, obesidade grau I, II ou III)
Menu interativo em loop, até o usuário optar por sair
Validação de entradas: o programa não quebra se o usuário digitar um valor inválido, e pede o número novamente
Tecnologias utilizadas
Python 3

Estrutura do código

O código é dividido em funções pequenas e independentes, cada uma responsável por uma única tarefa:

somar, subtrair, multiplicar, dividir — operações matemáticas
calcular_imc — cálculo e classificação do IMC
ler_numero — validação de entrada numérica
menu — exibição das opções
main — controla o fluxo principal do programa
